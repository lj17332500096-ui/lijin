# 历史归档目录

本目录保存已结束的验收交付、旧版评测运行、日志和报告快照，供追溯历史结果。它不是当前规范、生产数据源或活动代码目录。

## 放在这里

- 已结束批次的原始评测运行与配套报告。
- 已交付项目的输入、补丁、输出和交付记录快照。
- 不再活跃、但仍有审计或复盘价值的日志。

## 不放在这里

- 当前有效的架构、运行或开发说明；放在 `docs/`。
- 活动中的评测代码和用例；放在 `benchmark/` 或 `tests/`。
- 数据库、密钥、可恢复的生产状态或未经脱敏的敏感数据。
- 仍会被脚本、测试或生产流程引用的文件。

## 命名与保留

- 按主题和日期分组，例如 `runs_YYYY-MM/`、`reports_YYYY-MM/`、`logs_YYYY-MM/`。
- 同一批次保留能说明来源、配置和结论的配套材料。
- 归档内容默认不进入 Git；本 README 是目录约定。若某份历史材料需要版本追踪，应先脱敏并单独评估是否适合提交。
