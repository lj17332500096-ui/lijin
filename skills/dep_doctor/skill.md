# 依赖体检

## 何时触发
用户说「依赖体检 / 检查 requirements / 依赖清单有问题吗 / 扫一下依赖」等与 Python 依赖健康相关的请求时使用。

## 执行步骤
1. 调用 scan_dependencies(directory=...)（默认当前工作区目录，可指定到具体项目目录）；
2. 把工具报告整理成给用户的结论：重点说明——未锁定版本（浮动依赖）数量与示例、重复依赖及其冲突、
   建议动作（补 == 锁定 / 去重）；
3. 不要自动改文件：改动属于项目文件编辑，先给建议，用户点头再用 write_project_file / edit_project_file；
4. 需要“本机装什么新库”的语境（如用户问要不要装某包）不归本技能管，按普通问答处理。

## 边界
- 工具只读解析 requirements*.txt / pyproject.toml，不做安装、不扫 .venv；
- 发现危险项（如把 .env 打进去/密钥）保持通用安全规则，提醒并拒绝；
- 输出保持 AgentReply JSON；信息适合时可用 ui table 卡片展示清单。
