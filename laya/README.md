# Laya 目录

本目录集中保存 Laya 路由模型相关的训练数据构建、训练/转换脚本、评估和实验工具。生产路由接口及其 Runtime 接线应放在 `runtime/`。

## 放在这里

- Laya 专用数据集构建、清洗、校验和转换脚本。
- 训练、checkpoint 转换、阈值扫描、消融实验和评估代码。
- 训练环境与可复现流程说明，例如设备和依赖要求。
- 小型、可跟踪且来源明确的实验配置。

## 不放在这里

- 下载的上游源码副本；本地检查副本放在被忽略的 `_laya_inspect/`。
- 大型模型权重、checkpoint、缓存和批量中间数据；放到被忽略的 `data/` 或 `models/`。
- 生产路由的核心契约和通用执行逻辑；放在 `runtime/`。
- 包含密钥或未脱敏用户数据的训练样本。

## 维护约定

实验脚本应注明输入、输出、模型/数据版本及运行命令。评估结果与基准结论应附配置和指标；临时输出不要长期留在源码目录。
