# benchmark_fixture 测试修复报告

## 发现的问题

### 1. `auth.login()` 返回值不一致（核心问题）

**当前实现** (`app/auth.py`):
```python
def login(username, password):
    if username not in USERS or USERS[username] != password:
        return False
    create_session(username)
    return True  # 返回布尔值
```

**`run_tests_fixed.py` 期望**:
```python
result = auth.login("applicant", "app123")
assert result is not None and result["role"] == "applicant"
```
→ 期望返回 dict，访问 `.role` 属性

**测试结果**: `run_tests_fixed.py` 中登录测试全部失败 (AssertionError)

---

### 2. `test_login_wrong` 断言错误

**当前实现**: 失败时返回 `False`

**`run_tests_fixed.py` 期望**:
```python
assert auth.login("applicant", "wrong") is None
```
→ 期望返回 `None`，但实际返回 `False`

**测试结果**: `test_login_wrong` 失败

---

### 3. 缺少 `SESSIONS.clear()` (状态泄漏)

| 文件 | 是否清空 SESSIONS | 影响 |
|------|------------------|------|
| `run_tests_fixed.py` | ✓ 有 | 正常 |
| `test_auth.py` | ✗ 无 | 多次运行可能失败 |
| `test_auth_fixed.py` | ✗ 无 | 多次运行可能失败 |
| `test_auth_runner.py` | ✗ 无 | 多次运行可能失败 |

**风险**: `SESSIONS` 是全局字典，未清理会导致 token 冲突

---

### 4. import 路径不统一

- `run_tests_fixed.py`: 使用绝对路径 `sys.path.insert(0, "F:/Byong-hermes/...")`
- `test_auth.py`: 使用相对路径 `os.path.join(os.path.dirname(__file__), "..")`
- `test_auth_runner.py`: 使用 `os.chdir()` 改变工作目录

## 修复方案

### 方案 A: 修改 `auth.py` (推荐)

让 `login()` 返回 session dict，保持与 `run_tests_fixed.py` 一致：

```python
def login(username, password):
    """验证用户名密码，成功后自动创建 session 并返回 session dict，失败返回 None。"""
    if username not in USERS or USERS[username] != password:
        return None
    return create_session(username)
```

**同时修复** `test_login_wrong` 的断言：
```python
# run_tests_fixed.py 第 27 行
# 旧: assert auth.login("applicant", "wrong") is None
# 新: (无需修改，改为 None 后仍正确)
```

---

### 方案 B: 修复所有测试文件

保持 `auth.py` 不变，修复测试文件的断言：

**`run_tests_fixed.py`**:
```python
# 第 13-18 行
def test_login_applicant():
    result = auth.login("applicant", "app123")
    assert result is True  # 改为布尔判断
    print("✓ test_login_applicant")

def test_login_reviewer():
    result = auth.login("reviewer", "rev456")
    assert result is True
    print("✓ test_login_reviewer")

def test_login_admin():
    result = auth.login("admin", "admin789")
    assert result is True
    print("✓ test_login_admin")
```

**添加 SESSIONS 清理**:
```python
# 每个测试文件开头添加
from app import auth
auth.SESSIONS.clear()
```

## 建议

**推荐方案 A**: 修改 `auth.py` 使 `login()` 返回 session dict，理由：
1. 更合理的 API 设计（调用方需要 session 信息）
2. 与 `run_tests_fixed.py` 的预期一致
3. 减少测试文件中的修复工作量
