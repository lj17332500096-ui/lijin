# Legacy benchmark fixture collection

This directory preserves an older collection of benchmark-generated code snippets, scripts, and experiments. It is not the active benchmark suite; current maintained cases and runners live in `benchmark/`.

Keep this collection for historical replay only. New fixture source should be placed under a named topic in `benchmark/fixtures/` and documented there. Transient inline scripts generated by current tests should go under `var/tmp/` and must not accumulate here.
