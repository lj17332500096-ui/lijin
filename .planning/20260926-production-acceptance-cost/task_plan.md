# 生产路径验收与成本优化

## 目标

验收真实 `AgentRuntime.run_turn` 生命周期（包含状态、路由、工具包装、执行证据、Approval、CompletionGate 和 terminalization），修复回归；同时基于现有账本定位并优化可确定的冗余模型/工具成本，不引入外部付费调用。

## 阶段

1. [complete] 恢复仓库约束，定位生产路径测试与模型/工具成本记账。
2. [complete] 运行聚焦的生产闭环验收，修复失败并补充必要回归覆盖。
3. [complete] 分析一次 Run 的成本记账、重试和重复调用，实施安全的成本优化。
4. [complete] 执行相关验收，汇总结果、成本影响和未覆盖风险。

## 错误记录

| 错误 | 处理 |
|---|---|
| 根目录未找到 `AGENTS.md` / `CLAUDE.md` | 继续检查上级目录和 `.planning`，未假设存在项目指令 |
| 系统 Python 缺少 `agents` SDK，测试无法导入 | 定位项目虚拟环境或锁定依赖入口后重跑 |
