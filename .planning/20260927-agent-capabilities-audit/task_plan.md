# 插件、Skill、记忆与 Agent 接入专项审查

## 目标
只读检查插件扩展、Skill 技能、长期/项目记忆三类能力的定义、加载、Runtime 注册、Router 暴露、调用与状态可见性，确认是否真正接入 Agent 工作流，并记录风险及证据。

## 范围与限制
- 静态检查当前提交代码、配置样例、说明文档和针对性测试。
- 不修改产品代码，不启动模型/MCP，不读取或输出 `.env` 密钥，不执行写入型 Agent 工具。
- 区分配置/代码存在、Agent 可发现、Router 可调用、Runtime 实际执行、持久化/恢复已验证等层级。

## 阶段
- [x] 1. 盘点插件/MCP/本地 Skill 扩展来源及统一状态清单。
- [x] 2. 追踪 Skill 发现、按需加载、工具注册、路由与执行护栏。
- [x] 3. 追踪长期记忆和项目记忆的注册、读写、作用域、上下文接入。
- [x] 4. 核对现有测试与运行时证据，整理连接关系图及分级问题。
- [x] 5. 形成审计报告并更新本计划记录。

## 证据规则
- 每项结论标注源文件/行号及静态证据或测试证据。
- 不把目录中存在的 Skill/插件等同于已启用或可被 Agent 使用。
- 不把工具注册等同于 Router 能召回，也不把 Runtime 代码路径等同于生产环境真实服务可用。
- 不以往期修复记录代替当前代码复核。

## 发现摘要
- 插件/Skill/记忆均接入 Agent；Skill 与 MCP 工具最终经 Router/Runtime；语义记忆由原生工具和 RunContext 承接。
- 发现 MCP 失败后不自动重试、记忆关闭只禁写、global remember 声称双写但仅写全局、Episode 需手动 ingest、skill-assets 未检查目标 Skill 启用状态。
- 未读 `.env`、未启动 Provider/MCP、未跑测试，因此当前本机配置/真实外部连通性未确认。

无。
