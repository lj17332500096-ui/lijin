- 单阶段 Run 原来不受多阶段完成约束，明确工具任务可无工具完成；扩大约束后又暴露 `get_weather` 成功却被判外部事实无检索证据（`ExecutionEvidence.retrieval_evidence()` 漏列该工具）。
- 成功只读工具的 `_mut_outcome` 默认值是 `UNKNOWN`；该状态被误传到阶段不确定路径，使正常天气查询进入 needs_user_input。
- 多阶段结束后，Runtime 原来允许模型重复调用任何工具，造成真实模型在拿到数据后重复查询/计算。
- 修复后真实 Agnes Run 已按 `get_weather` → `calculate` 顺序执行并完成，实时样本温差为 5.4°C。
