# TUI Codex 风格显示优化

## 目标
让 TUI 的对话、工具活动和 Run 终态更接近 Codex 的清晰分层，同时消除重复输出和终态状态误导；统一所有固定界面文案为中文。

## 阶段
- [complete] 检查现有 TUI 消息、工具和状态呈现
- [complete] 优化流式回复标题、工具摘要与终态状态
- [complete] 将状态栏、菜单、提示、弹窗、检查面板和快捷键说明统一为中文
- [complete] 检查差异并记录未执行的动态验收

## 本轮范围
- 流式回答类型标签合并进原始 assistant 消息头，移除多余的 FORGE 元信息行。
- 折叠工具组显示完成/失败/运行中数量和总耗时。
- 顶部状态栏区分部分完成、受阻、需要用户输入、取消与失败。
- TUI 固定界面文案与帮助内容统一为中文。
- 快捷键名称、斜杠命令、FORGE 品牌、模型与工具原名、路径和协议字段保留原样。
- 未运行测试或物理终端验收，按当前任务约束仅检查 diff 与空白错误。
