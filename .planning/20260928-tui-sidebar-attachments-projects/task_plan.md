# TUI 对话、项目与附件改造计划

## 目标
在当前 Textual TUI 中实现可切换的左侧会话列表、项目创建/选择/文件夹绑定，以及文件和文件夹添加入口，并正确连接已有 Runtime 与存储状态。

## 阶段
1. [完成] 盘点会话、项目、文件安全边界和 TUI 布局接口。
2. [完成] 实现侧栏会话列表与真实切换/新建会话。
3. [完成] 实现项目创建/选择和文件夹绑定。
4. [完成] 实现文件添加入口、本轮附件绑定与 Runtime 上下文注入。
5. [完成] Python 语法编译与 git diff 空白检查通过；未运行测试或启动真实 TUI。

## 决策
- 左侧栏以键盘 ↑↓/Enter 操作，也提供按钮和 Ctrl+S；会话切换显式传 `task_container_id` 并恢复持久化对话。
- 项目是一个 `proj-` Runtime 容器会话，所选目录绑定为 WorkLocation。
- 文件附件复制到容器专属的 `forge_data/projects/<container>/attachments/`，只在发送下一条消息时绑定；每轮最多 8 个文件、总计不超过 50 MB；密钥与证书文件拒绝添加。
- 修改 FileScope 与文件读取根，使受 Runtime scope 授权的项目附件可被核心文件工具读取；附件表绑定也按当前容器 ID 再校验一次。
- 保留工作区开始前已存在的 Runtime 能力问句修复改动。

## 错误记录
| 错误 | 处理 |
|---|---|
| 一次 PowerShell 查看计划命令把 `Get-Content` 的路径参数拆开 | 规划文件已写入；后续改用显式 `Join-Path` |
| 一次 apply_patch 找不到 app.py 上下文 | 没有落盘；拆分为更小 patch 后完成 |
| 一次 CSS patch 上下文不匹配 | 没有落盘；重新读取目标区后分块完成 |
