# Historical Public Activity browser E2E

This directory contains the previous browser harness, its screenshots/results, and isolated example workspaces from 2026-09-09. The scripts target the former `/api/*` application, which was removed on 2026-09-22 when the web UI was frozen.

These files are preserved as historical evidence and are not a current browser acceptance suite. Current backend projection and streaming acceptance is covered by `tests/test_public_activity.py` and `tests/test_stream_pipe.py`. Do not run the old scripts against the current app without first restoring their matching archived frontend/API contract.
