# 此刻 NOW：第一轮 UI 调整

完成日期：2026-09-08。按用户提供的参考图，实施首页重排、任务导航、输入区整理与手机端适配。

## 已完成

- 首页：标题下方直接输入，四个紧凑快捷入口，三条最近任务和查看全部入口。
- 导航：可收起任务侧栏、搜索、全部任务、进行中、等待确认、资料和设置；任务列表支持名称筛选。
- 输入区：合并文件夹入口，文件夹名省略显示、完整路径保留在提示中；自适应高度、空内容禁用发送、中文输入法组合输入保护。
- 手机：抽屉导航、单列快捷入口、紧凑工具栏、安全区与动态视口高度；手机 Enter 换行。
- 状态处理：首页与任务分开保留内存草稿及附件；返回首页清除当前任务和文件夹；过期的任务加载响应不会覆盖新页面。
- 附件与文件夹：新首页上传前建立附件归属；已有任务选择文件夹更新当前任务；修复来源菜单返回后上传及菜单异步关闭问题。

## 运行

需要 Node.js、Playwright、Microsoft Edge，以及运行在 http://127.0.0.1:8765 的本地服务。

```powershell
node tests/ui_round1_20260908/check_ui.cjs
node tests/frontend_smoke.js
```

如果 Playwright 位于共享运行时，请先将其包目录配置到 `NODE_PATH`。
