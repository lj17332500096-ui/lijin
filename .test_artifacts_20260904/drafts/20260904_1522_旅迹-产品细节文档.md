## 一、功能优先级排序（MoSCoW 法）

### 🔴 Must Have（MVP 必须）
| 功能 | 说明 | 优先级理由 |
|------|------|----------|
| **照片导入** | 支持相机、相册、微信图片导入 | 核心入口，无此无法启动 |
| **AI 识别** | 自动识别时间、地点、人物、场景标签 | 自动化整理的基础 |
| **时间线视图** | 按日期排列照片，一目了然 | 最直观的整理形式 |
| **游记生成** | 基于照片内容自动生成文字描述 | 核心价值点 |
| **基础分享** | 导出为图片/文字，分享到社交平台 | 闭环的关键一步 |

### 🟡 Should Have（重要但不紧急）
| 功能 | 说明 | 优先级理由 |
|------|------|----------|
| **地图视图** | 在地图上标记拍摄地点，生成轨迹 | 增强空间感，但可延后 |
| **多风格切换** | 文艺/干货/幽默/极简四种文风 | 提升个性化，但初版可用默认风格 |
| **相册管理** | 创建/编辑/删除相册，手动调整 | 用户需要一定控制力 |
| **隐私设置** | 公开/私密/仅自己可见 | 安全需求，但可简单实现 |

### 🟢 Could Have（锦上添花）
| 功能 | 说明 |
|------|------|
| 多人协作上传 | 家庭成员共同上传同一趟旅行 |
| 语音转文字 | 口述旅行故事，AI 转化为游记 |
| 背景音乐生成 | 为游记配上适合的氛围音乐 |
| AR 相册 | 扫描照片触发 AR 效果 |

### ⚪ Won't Have（暂不规划）
- 实体书打印服务（需要供应链管理）
- 旅行社区/社交功能（偏离核心定位）
- 机票酒店预订（边界过宽）

## 二、核心用户旅程设计

### 旅程 1：初次使用（新手引导）
```
启动 App → 欢迎页介绍核心价值 → 授权相册权限 → 导入首批照片
→ AI 自动整理展示时间线 → 一键生成第一篇游记 → 分享成功 → 引导订阅
```

**关键设计点**：
- 首次导入建议 5-10 张照片，避免选择困难
- 生成游记后提供"满意/不满意"反馈，用于优化模型
- 分享成功后展示成就徽章，增强成就感

### 旅程 2：日常使用（单次旅行）
```
打开 App → 选择"新建旅行" → 导入/拍摄照片
→ AI 自动识别地点、时间、人物 → 用户确认/微调标签
→ 选择游记风格 → AI 生成游记草稿 → 用户编辑调整
→ 预览最终效果 → 分享/导出 → 归档到"我的旅行"
```

**关键设计点**：
- 导入流程要快，支持批量导入
- 识别结果要允许手动修正（如纠正地点名称）
- 游记编辑要简单易用，支持语音输入补充细节

### 旅程 3：回顾与分享（长期价值）
```
打开 App → 查看"年度旅行报告"或"那年今日"
→ 选择某次旅行 → 浏览时间线/地图视图
→ 分享给朋友/发布到社交媒体
→ 生成精美图片海报
```

**关键设计点**：
- 年度报告要数据可视化，有分享欲
- "那年今日"要有情怀感，推送时机要准
- 海报模板要多样，满足不同审美

## 四、核心交互细节

### 1. 照片导入体验
- **智能推荐**：导入时自动推荐"创建新旅行"，基于 GPS 和日期
- **批量操作**：支持多选、批量打标签、批量移动
- **去重检测**：自动识别重复照片，提示用户清理

### 2. AI 识别反馈
- **即时预览**：每张照片识别完成后立即显示标签
- **可修正性**：点击标签可修改，系统学习用户偏好
- **置信度提示**：低置信度的识别结果用灰色显示，暗示可能需要确认

### 3. 游记编辑
- **所见即所得**：编辑界面与最终分享效果一致
- **模板化修改**：一键替换整段风格，或局部调整
- **版本历史**：保留修改历史，可回退到任意版本

## 五、数据模型（简化版）

```
User
├── id: string
├── name: string
├── avatar: url
└── preferences: {
    ├── default_style: '文艺'|'干货'|'幽默'|'极简'
    ├── language: 'zh'|'en'|'ja'
    └── privacy: 'public'|'private'|'friends'
}

Trip
├── id: string
├── user_id: string
├── title: string
├── start_date: datetime
├── end_date: datetime
├── location: {
│   ├── city: string
│   ├── province: string
│   └── country: string
│   }
├── photos: [Photo]
├── itinerary: [ItineraryItem]
├── travelogue: Travelogue
└── tags: [string]

Photo
├── id: string
├── trip_id: string
├── file_url: string
├── captured_at: datetime
├── location: { lat, lng }
├── tags: [string]  // AI 识别结果
├── description: string  // AI 生成
└── user_edits: {  // 用户修正
    ├── tags: [string]
    └── description: string
}

Travelogue
├── id: string
├── trip_id: string
├── style: '文艺'|'干货'|'幽默'|'极简'
├── content: string  // 生成的游记文字
├── sections: [Section]
├── cover_photo: Photo
└── share_url: string
```
