# 安全校验机制说明

## 什么是安全校验机制？

安全校验机制是用于验证用户身份和访问权限的技术手段，确保只有授权用户才能使用特定服务或API。

## 常见类型

### 1. API Key 认证
- **原理**：用户生成唯一密钥，在请求时携带验证身份
- **使用方式**：通常在 HTTP Header 中传递，如 `Authorization: Bearer <API_KEY>`
- **优点**：简单、易实现、可限制访问频率
- **缺点**：密钥泄露风险需妥善保管

### 2. OAuth 2.0
- **原理**：通过第三方授权颁发临时访问令牌
- **适用场景**：需要访问用户数据但不获取密码的场景
- **流程**：用户授权 → 获取授权码 → 换取访问令牌

### 3. JWT (JSON Web Token)
- **原理**：包含用户信息的加密令牌，服务端验证签名
- **优点**：无状态、可包含权限信息、跨域友好

### 4. IP 白名单
- **原理**：只允许指定IP地址的请求通过
- **适用**：企业级API、内部服务调用

## 您的 OPENAI_API_KEY 安全建议

1. **不要硬编码在代码中**
   - 使用环境变量或配置文件
   - 添加到 `.gitignore` 避免提交到版本控制

2. **定期轮换密钥**
   - 发现泄露立即在平台撤销并重生成
   - 长期不用的服务及时清理密钥

3. **限制权限范围**
   - 按项目/用途创建不同密钥
   - 设置月消费预算上限

4. **监控使用情况**
   - 定期检查API使用日志
   - 关注异常调用行为

## 本助手的安全处理

如果您在本助手的 `.env` 文件中配置了 `OPENAI_API_KEY`：
- 该密钥仅用于当前会话的工具调用
- 不会被持久化存储或分享给第三方
- 敏感信息（如密码、密钥）不会存入长期记忆
