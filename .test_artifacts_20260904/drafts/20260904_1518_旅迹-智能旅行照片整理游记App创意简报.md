# 创意简报：旅迹 · 智能旅行记忆整理 App

---

## 一句话创意
**"拍照即整理，旅行即成书"** —— 让用户只需上传照片，AI自动识别地点、时间、人物，生成图文并茂的旅行游记。

---

## 成品形态
**移动端 App**（iOS + Android）  
- 核心功能：照片导入 → AI识别分类 → 自动生成游记 → 一键分享/导出
- 延伸形态：网页版相册、纸质书打印服务（可选）

---

## 为谁、为什么做
| 目标用户 | 痛点 | 价值主张 |
|----------|------|----------|
| **旅行爱好者** | 照片多、懒得整理、朋友圈九宫格应付了事 | 自动整理 + 自动生成游记，省去 2-3 小时/次的整理工作 |
| **家庭用户** | 全家出游照片散落各处，想留住回忆却无从下手 | 多人协作上传、按人/按天分组、自动成长纪念册 |
| **内容创作者** | 需要持续产出旅行内容但缺乏时间整理素材 | 一键生成小红书/公众号格式游记，降低创作门槛 |
| **情侣/夫妻** | 共同旅行照片难共享、难回溯 | 双人相册、自动生成"我们的旅行故事" |

---

## 核心功能模块

### 1. 智能导入与整理
- 支持从相机、手机相册、微信、云盘一键导入
- AI 自动识别：拍摄时间、GPS 地点、人物面孔、场景类型（风景/美食/人物/建筑）
- 自动生成时间线视图（按日期排列）+ 地图视图（按地点标记）

### 2. AI 游记生成
- 基于照片内容 + 用户补充文字（可选），自动生成结构化工游记：
  - **开头**：旅行背景、心情引入
  - **主体**：按天/按景点分章节，每段配 3-5 张精选照片 + 描述
  - **结尾**：总结、推荐、预算提示
- 支持多种风格：文艺风、干货风、幽默风、极简风
- 可一键切换语言（中/英/日等）

### 3. 社交与分享
- 内置模板：小红书笔记、朋友圈九宫格、公众号文章、微博长图
- 一键导出 PDF/电子书，支持打印成实体相册
- 私密空间：仅自己可见；公开分享：生成专属链接

### 4. 记忆回顾
- "那年今日"：每年推送当年同日的旅行记忆
- 年度旅行报告：生成全年旅行数据可视化（去了几个城市、拍了几千张照片、总里程等）

## 技术可行性评估

| 模块 | 技术现状 | 难度 | 备注 |
|------|----------|------|------|
| 照片 OCR + 地点识别 | 成熟 | 低 | 可用 Google ML Kit / Apple Vision / 百度 OCR |
| 人物识别 | 成熟 | 低 | 本地人脸识别 API 丰富 |
| 游记生成 | 成熟 | 中 | 基于 LLM（GPT/Claude/DeepSeek）+ 模板系统 |
| 地图轨迹可视化 | 成熟 | 中 | 高德/Mapbox SDK |
| 多端同步 | 成熟 | 中 | 需自建后端或 Firebase |

**关键能力缺口**：
- ❌ **生成图片/视频**：App 需要接入图像生成 API（如 DALL-E、Midjourney API、即梦 API）
- ❌ **运行任意代码**：需要服务端部署，或用户自行搭建

---

## 最核心的第一步
**MVP 原型验证**：
1. 做一个简单的网页版 Demo（React/Vue + Python FastAPI）
2. 核心流程：上传图片 → 调用 LLM 生成游记 → 展示结果
3. 验证用户是否真的需要这个功能（找 10-20 个目标用户测试）

**具体落地路径**：
- Step 1：用现有工具（如 ChatGPT + Python）手动跑通流程，验证效果
- Step 2：开发 MVP Web 版，接入 DeepSeek/ChatGPT API
- Step 3：根据反馈迭代，再考虑原生 App
