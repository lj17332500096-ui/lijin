# ⚠️ **上界不是保守，是必需**（10-05 CI run 37350998914 实据教训）
#
# 本文件原先写 `openai-agents>=0.22.0`（**无上界**），于是：
#   - 本地 venv固定 0.22.0
#   - CI 每次 `pip install` 拉**当时最新版**
#   ⇒ 同一份代码、同一份测试，两边结论不同。
# 实际踩到的：0.22.0 的 `default_tool_error_function` 返回
# `"... Please try again. Error: {str(error)}"`（带 detail）；
# 新版出于安全加固（不把原始异常泄露给模型）**删掉了该后缀**
# ⇒ `test_outside_workspace_rejected` 在 CI 红、本地绿，
#   且**本地怎么复现都复现不出来**（试过短名 tempdir / 无向量 / 同形短名根，
#   全都绿）。
#
# 教训：**「本地绿」的前提是依赖集相同**。开放上界让这个前提天然不成立，
# 于是任何依赖行为变更都会伪装成「代码缺陷」，把排查成本推到极高。
#
# 策略：给每个 `>=` 加**兼容上界**（下一个minor 版本的下一位）。
# 上界过紧（`==`）会让安全补丁也装不上；上界缺失则等于没有 CI 护栏。
# 升级流程：本地 `pip install -U` → 跑全量 → 改这里的上界 → 提交。
