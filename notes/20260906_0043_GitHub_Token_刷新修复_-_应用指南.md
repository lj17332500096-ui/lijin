# GitHub Token 刷新修复 - 应用指南

## 问题诊断

**文件**: `my_creative_agent/github_fetch.py` 第 111 行

**当前代码（有问题）**:
```python
except HTTPError:
    pass
```

**问题**: 所有 HTTPError（包括 500/502/503）都降级到公开 API，不符合 GitHub API 最佳实践。

## 修复方案

### 步骤 1：修改 github_fetch.py

打开 `my_creative_agent/github_fetch.py`，找到第 111-112 行：

**修改前**:
```python
    except HTTPError:
        pass
```

**修改后**:
```python
    except HTTPError as exc:
        # 只对认证错误降级；服务器错误（5xx）和其他错误直接抛出
        if exc.code not in (401, 403):
            raise
```

### 步骤 2：运行测试验证

```bash
cd my_creative_agent
python -m pytest tests/test_github_fetch.py -v
```

## 修复逻辑

- **401/403（认证错误）**: Token 过期或无效 → 降级到公开 API
- **500/502/503（服务器错误）**: GitHub 服务端问题 → 直接抛出异常
- **404（仓库不存在）**: 仓库不存在 → 直接抛出异常

这样可以更准确地反映问题原因，避免掩盖 GitHub 服务端故障。
