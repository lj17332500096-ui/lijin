# GitHub Token 刷新修复 - 总结

## 问题
`github_fetch.py` 第 111 行的 `_download_archive` 函数对所有 `HTTPError` 统一降级到公开 API，没有区分认证错误和服务器错误。

## 修复
**文件**: `my_creative_agent/github_fetch.py`  
**位置**: 第 111-112 行

**修改前**:
```python
except HTTPError:
    pass
```

**修改后**:
```python
except HTTPError as exc:
    # 只对认证错误降级；服务器错误（5xx）和其他错误直接抛出
    if exc.code not in (401, 403):
        raise
```

## 效果
- 401/403（Token 过期/无效）→ 降级到公开 API ✓
- 500/502/503（GitHub 服务端错误）→ 直接抛出异常 ✓
- 404（仓库不存在）→ 直接抛出异常 ✓
