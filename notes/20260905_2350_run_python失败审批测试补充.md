# 运行失败代码的审批测试补充

## 测试场景
验证 `run_python` 工具执行失败时的审批流程和后续处理：
1. 代码执行失败触发审批
2. 批准后重新执行
3. 拒绝后任务正确终止

## 现有测试覆盖
- `test_code_exec.py`: 沙箱安全、成功执行、失败执行
- `test_codex_loop.py`: 失败→修复→重跑→四段总结
- `test_approval.py`: 审批门控、批准/拒绝逻辑

## 需要补充的测试
以下测试用例可补充到 `test_approval.py`:

```python
def test_run_python_failure_triggers_approval(self):
    """run_python 执行失败时应触发审批等待"""
    task = self.manager.create_task("s1", "跑代码")
    self.gate.begin(task.id, channel="chat")
    decision = asyncio_call(self.gate.check("run_python", {"code": "raise ValueError('fail')"}))
    self.assertIsNotNone(decision)
    self.assertIn("需要审批", decision)
    self.assertEqual(len(self.gate.pending_this_run), 1)
    self.gate.end()

def test_run_python_approved_then_executed(self):
    """批准后 run_python 应能真正执行"""
    task = self.manager.create_task("s1", "跑代码")
    self.gate.begin(task.id, channel="chat")
    decision = asyncio_call(self.gate.check("run_python", {"code": "print('ok')"}))
    self.assertIsNotNone(decision)  # 第一次拦截
    approval_id = self.gate.pending_this_run[0]
    self.manager.decide_approval(approval_id, "approved", actor="user")
    # 批准后放行
    decision2 = asyncio_call(self.gate.check("run_python", {"code": "print('ok')"}))
    self.assertIsNone(decision2)
    self.gate.end()
```

## 关键设计点
1. `ApprovalGate.check()` 返回 None = 放行，非空 = 拦截文本
2. 同一参数第二次调用会检查已批准的记录
3. 审批状态持久化到 `approvals` 表，支持跨轮次恢复

## 运行测试
```bash
python -m pytest tests/test_approval.py -v
```
