# 读书笔记技能 · 草稿结构

## 目录结构
```
reading-notes/
├── SKILL.md              # 必需，入口文件
├── agents/openai.yaml    # 可选，技能名片
├── scripts/extract.py    # 可选，PDF提取脚本
├── assets/
│   ├── template.md       # 笔记模板
│   └── example.md        # 示例笔记
└── references/
    └── best-practices.md # 参考文档
```

## SKILL.md 核心内容

### frontmatter
```yaml
---
name: reading-notes
description: 结构化读书笔记生成助手。支持书籍摘要、核心观点提炼、金句摘录、行动清单与反思记录。
---
```

### 技能主体
1. 用途说明
2. 触发条件（书名、章节摘录、PDF链接等）
3. 核心流程四步：
   - 获取书籍信息
   - 提取核心内容
   - 生成结构化笔记（6个模块）
   - 保存归档

### 笔记模块
- 📖 书籍基本信息
- 🎯 核心观点（3-5条）
- 💬 金句摘录（3-5条）
- 💡 个人启发/反思
- ✅ 行动清单
- ❓ 待解决问题

### 约束条件
- 忠实原著，不虚构
- 观点需注明出处
- 金句不超过原文20%
- 行动项要具体可执行

## 配套模板（assets/template.md）
标准 Markdown 格式，包含所有模块占位符。
