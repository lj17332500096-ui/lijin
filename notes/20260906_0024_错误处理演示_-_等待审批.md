## 待运行代码

```python
# 演示错误处理 - 运行会失败的代码并继续

print("=== 演示 1: 除以零错误 ===")
try:
    result = 10 / 0
except ZeroDivisionError as e:
    print(f"捕获错误: {e}")
    result = 0  # 提供默认值

print(f"结果: {result} (使用默认值)")

print("\n=== 演示 2: 键错误 ===")
data = {"name": "test"}
try:
    value = data["missing_key"]
except KeyError as e:
    print(f"捕获错误: {e}")
    value = "default"  # 提供默认值

print(f"值: {value} (使用默认值)")

print("\n=== 演示 3: 类型错误 ===")
try:
    result = "hello" + 5
except TypeError as e:
    print(f"捕获错误: {e}")
    result = "hello" + str(5)  # 修正类型

print(f"结果: {result}")

print("\n=== 程序继续运行 ===")
print("✓ 所有错误都已处理，程序正常结束")
print(f"✓ 最终输出: {result}")
```

## 关键知识点
1. **try-except** - 捕获并处理异常
2. **默认值** - 出错时使用备选方案
3. **类型转换** - 修复类型不匹配问题
4. **继续执行** - 错误处理后程序不中断
