# TokenRefreshTests 补充说明

## 已准备测试代码

测试类 TokenRefreshTests 包含 4 个测试用例：

1. test_token_expired_falls_back_to_public - Token 401 降级
2. test_token_forbidden_falls_back_to_public - Token 403 降级  
3. test_server_error_raises_not_fallback - 服务器 502 抛出异常
4. test_valid_token_no_fallback - 有效 token 不降级

## 需要执行的操作

将测试代码追加到 my_creative_agent/tests/test_github_fetch.py 文件末尾（在 if __name__ == "__main__": 之前）。

## 验证命令

python -m pytest tests/test_github_fetch.py::TokenRefreshTests -v
