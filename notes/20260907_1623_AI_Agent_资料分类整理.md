## 一、Agent Skills（技能模块）
给编码 Agent（Claude Code/Codex/Cursor）新增能力的插件，一条命令安装。

| 技能名称 | 功能说明 |
|---------|---------|
| Project Graveyard | 分析你放弃的副项目，找出死因并建议重启哪个值得做 |
| Scope Creep Detector | 检查代码变更是否超出原定范围 |
| Commit Archaeologist | 从 Git 历史重建代码/文件为何存在 |
| Dependency Doctor | 扫描依赖清单，检查版本锁定、废弃包、重复约束 |
| Advisor Orchestrator Worker | 多模型协作框架（Claude Fable 5 + GPT-5.6 + Gemini 3.7 Flash） |
| Self-Improving Agent Skills | 用 Gemini 和 ADK 自动优化 Agent 技能 |
| Thinking Out Loud | 推理过程可视化技能 |

## 二、Starter AI Agents（入门级 Agent）
单文件即可运行，只需 API Key，适合快速上手。

### 内容创作类
- **AI Blog to Podcast**：博客 URL → 音频播客
- **AI Meme Generator**：驱动真实浏览器生成表情包
- **AI Music Generator**：输入提示词 → 输出 MP3

### 数据分析类
- **AI Data Analysis**：用自然语言查询 CSV/Excel
- **AI Data Visualisation**：数据可视化 Agent
- **xAI Finance Agent**：基于 Grok 的实时股票分析
- **OpenAI Research Agent**：多 Agent 协作的深度研究

### 生活服务类
- **AI Travel Agent**：个性化旅行行程规划
- **AI Breakup Recovery**：情感支持 Agent 团队
- **AI Life Insurance Advisor**：保险咨询顾问

### 技术与工具类
- **Web Scraping AI Agent**：描述需求 → 自动抓取网页
- **Multimodal AI Agent**：视频分析 + 网页搜索一体化
- **Mixture of Agents**：多 LLM 回答 → 聚合最优结果
- **AI x402 Paying Agent**：自带钱包、按次付费的 Agent
