# 修复总结：登录后刷新页面会退出

## 修改文件清单

### 1. src/auth.ts（主要修复）
- 导入 `SessionStore`
- 添加构造函数，页面加载时从 sessionStorage 恢复 token
- login() 成功后调用 SessionStore.get().saveToken(data.token)
- refresh() 成功后调用 SessionStore.get().saveToken(data.token)

### 2. src/session.ts（存储方式修正）
- saveToken: localStorage → sessionStorage
- loadToken: localStorage → sessionStorage
- clear: localStorage → sessionStorage
- 移除 FIXME 注释

### 3. tests/auth.test.ts（测试更新）
- 新增断言验证 token 已保存到 sessionStorage

### 4. README.md（文档更新）
- 标记问题 #1 为已修复

## 验证命令
```bash
npm test      # 运行测试
npm run build # 类型检查
```

## 修复原理
之前 token 只存在内存变量 `this.token`，刷新页面后 JS 对象重建，token 丢失。
现在：
1. 登录/刷新后 token 持久化到 sessionStorage
2. 页面加载时构造函数自动从 sessionStorage 恢复
3. sessionStorage 在标签页关闭前保持有效，刷新不会丢失
