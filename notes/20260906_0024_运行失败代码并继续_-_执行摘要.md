### 脚本 1: 基础错误类型演示
**文件**: `demo/error_demo.py` (待创建)

```python
def divide_by_zero():
    result = 10 / 0  # ZeroDivisionError

def key_error_demo():
    data = {"name": "test"}
    return data["missing_key"]  # KeyError

def type_error_demo():
    result = "hello" + 5  # TypeError

# 错误处理模式
print("=== 测试 1: 除以零 ===")
try:
    divide_by_zero()
except ZeroDivisionError as e:
    print(f"捕获到错误: {type(e).__name__}: {e}")
    print("✓ 程序继续运行")
```

### 脚本 2: 真实场景演示
**文件**: `demo/error_handling_demo.py` (待创建)

```python
import json
from pathlib import Path

# 模拟读取配置文件（文件不存在）
config_path = Path("nonexistent_config.json")
if not config_path.exists():
    print("⚠ 文件不存在，使用默认配置")
    config = {"timeout": 30, "retries": 3}

# 访问不存在的键
try:
    value = config["api_key"]
except KeyError as e:
    print(f"⚠ 缺少键: {e}")
    value = None  # 使用默认值

# 继续执行
print(f"✓ 使用 timeout: {config.get('timeout', 30)}")
print("✓ 错误处理后继续执行")
```

## 关键模式
1. **try-except** - 捕获特定异常
2. **默认值** - 提供降级方案
3. **日志记录** - 记录错误信息
4. **继续执行** - 不中断主流程
