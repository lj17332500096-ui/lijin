# GitHub Token 刷新修复 - 最终报告

## 问题诊断
**文件**: `my_creative_agent/github_fetch.py` 第 111-112 行

**问题**: `_download_archive` 函数对所有 `HTTPError` 统一降级到公开 API，没有区分：
- 401/403（认证错误）→ 应降级到公开 API
- 500/502/503（服务器错误）→ 应直接抛出异常
- 404（仓库不存在）→ 应直接抛出异常

## 修复内容

### 代码修改
**位置**: `github_fetch.py` 第 111-112 行

```python
# 修改前
except HTTPError:
    pass

# 修改后
except HTTPError as exc:
    # 只对认证错误降级；服务器错误（5xx）和其他错误直接抛出
    if exc.code not in (401, 403):
        raise
```

### 测试用例
**文件**: `tests/test_github_fetch.py`

新增 `TokenRefreshTests` 测试类，包含 3 个测试：
1. `test_token_expired_falls_back_to_public` - 401 降级
2. `test_server_error_raises_not_fallback` - 502 不降级
3. `test_valid_token_no_fallback` - 有效 token 不降级
