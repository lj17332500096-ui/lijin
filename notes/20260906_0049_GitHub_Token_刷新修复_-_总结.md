# GitHub Token 刷新修复 - 总结

## 问题
`github_fetch.py` 第 111-112 行对所有 HTTPError 统一降级，没有区分认证错误和服务器错误

## 修复
**文件**: `my_creative_agent/github_fetch.py` 第 111-112 行

```python
# 修改前
except HTTPError:
    pass

# 修改后
except HTTPError as exc:
    # 只对认证错误降级；服务器错误（5xx）和其他错误直接抛出
    if exc.code not in (401, 403):
        raise
```

## 测试
**文件**: `my_creative_agent/tests/test_github_fetch.py`

添加 TokenRefreshTests 类，包含 4 个测试：
- test_token_expired_falls_back_to_public - 401 降级
- test_token_forbidden_falls_back_to_public - 403 降级
- test_server_error_raises_not_fallback - 502 不降级
- test_valid_token_no_fallback - 有效 token 不降级
