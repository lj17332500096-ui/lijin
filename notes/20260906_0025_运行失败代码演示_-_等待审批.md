```python
print("=== 演示：运行会失败的代码并继续 ===\n")

# 示例 1: 除以零
print("1. 除以零测试:")
try:
    result = 10 / 0
except ZeroDivisionError as e:
    print(f"   捕获错误: {e}")
    result = 0
print(f"   使用默认值: result = {result}\n")

# 示例 2: 键不存在
print("2. 键不存在测试:")
data = {"name": "test"}
try:
    value = data["missing_key"]
except KeyError as e:
    print(f"   捕获错误: {e}")
    value = "default"
print(f"   使用默认值: value = {value}\n")

# 示例 3: 类型错误
print("3. 类型错误测试:")
try:
    result = "hello" + 5
except TypeError as e:
    print(f"   捕获错误: {e}")
    result = "hello" + str(5)
print(f"   修正后结果: {result}\n")

print("=== 程序继续运行 ===")
print("✓ 所有错误都已处理，程序正常结束")
print(f"✓ 最终输出: result = {result}")
```

## 关键点

2. 提供默认值或修正值
3. 程序继续执行不中断
4. 展示常见的 Python 错误类型
