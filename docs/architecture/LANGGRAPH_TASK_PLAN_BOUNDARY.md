# 当前工具筛选与任务计划职责

2026-10-01 起，旧的关键词 Tool Router 与独立实验 Pipeline 已退役。普通 Run 使用 LangGraph 工作流完成请求分析、候选工具筛选、Runtime 计划安装、执行、复核及一次有界补充。

LangGraph 只决定当前请求需要暴露哪些已注册工具，并提供任务阶段建议。Runner 会剔除清单外名称、补入 Runtime 计划要求的工具，并把计划限制在已选工具范围。每次工具调用仍须经过 Runtime 的安全、文件范围、审批、预算与执行证据链；筛选或分析出错时回退到完整注册清单。

模型档位选择仍位于 `runtime/router.py`，它只选择模型配置，不筛选工具。
