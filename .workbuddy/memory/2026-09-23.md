## Laya 路线A · GRPO 训练失败 → 改 SFT（方案1，user 拍板）

### GRPO 验证结论（user 拍板"先走(b)"后 CPU 全量验证）
- 453 条 1 epoch GRPO（37min）reward 单调恶化：-1.62 → -3.26 → -4.24 → avg -4.37
- 根因：单样本 REINFORCE 无 group baseline，453 条小数据方差极大，policy 被随机扰动往错误方向推；proper_reward log score 项主导
- **结论：453 条二分类小数据不适合 RLCD/GRPO（Laya 官方 RLCD 是 30k 大数据场景）**

### 改方案1：SFT（user 拍板）
- `train_laya_forge.py` 加 `--mode sft`（默认 sft，`--mode grpo` 保留原逻辑）
- `_sft_step`：用 gold one-hot 在 K option 上做 `F.cross_entropy(logits, target.argmax(-1))`，不用采样/reward/policy gradient
- 453 条 SFT 1 epoch CPU 后台跑中（task yXEDl0，~37min），落盘 `data/laya_forge/forge_finetuned_sft/`
- 验证判据：loss 单调降（不像 GRPO 的 reward 恶化）；训练完对 154 条人工标注 test 跑 `eval_laya_forge.py` 验收 >95%
