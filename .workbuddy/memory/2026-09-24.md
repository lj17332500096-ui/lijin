## Spark 思考链关闭（已解决）

Spark-X2.5 的 reasoning_content 思考链可以**用 `--reasoning off` 彻底关闭**（实测有效）：
- 默认：content 为空、reasoning_content 占满 token、finish_reason=length
- `--reasoning off`：content="1+1等于2。"、finish_reason=stop、思考链消失

llama.cpp 相关参数（llama-server --help 查证）：
- `--reasoning [on|off|auto]`：思考开关（默认 auto，从模板检测）
- `--reasoning-budget N`：思考 token 预算，0=立即结束，-1=不限制
- `--reasoning-format`：思考内容返回格式（deepseek 放 reasoning_content）
- `--reasoning-effort`：思考强度（minimal/low/medium/high/xhigh/max）

**修正之前记忆**：之前写的"需调大 max_tokens 或 --reasoning-preserve"不准确，
`--reasoning-preserve` 只是"保留思考痕迹在历史里"，不是关闭思考。正确关闭 = `--reasoning off`。

当前 server 已用 `--reasoning off` 重启运行中（task S3y5hp）。
